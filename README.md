# 🔎 VK OSINT

**VK OSINT** is a tool for analyzing public VK profiles and automatically collecting available open-source information.

## ✨ Features

* 👤 First and last name
* 🆔 Profile ID and URL
* 🔗 Username and public links
* 📍 City and profile information
* 📝 Bio and status
* 📞 Public contact information
* 🖼️ Profile avatar
* 📊 Structured OSINT report

## 🎯 Purpose

The tool helps quickly analyze a **VK profile's public digital footprint**, collect publicly available information, and organize the results for further OSINT research.

> Use this tool only for publicly available information and in accordance with applicable laws.
